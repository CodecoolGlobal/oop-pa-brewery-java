# Brewery Management System - Starter Code

## Project Setup

1. Ensure you have Java 21 installed
2. Ensure you have Maven installed
3. Open this project in your IDE

## Before You Start

1. **Configure Maven Dependencies**: Open `pom.xml` and add the required dependencies:
   - JUnit 5 (for testing)
   - Mockito (for mocking in tests)

2. **Review the starter code**: Familiarize yourself with the existing classes:
   - `Beer.java` - Basic beer class (needs extension)
   - `Brewer.java` - Basic brewer class (needs extension)
   - `Brewery.java` - Partially implemented brewery (many TODOs)
   - `BreweryTest.java` - Empty test class (needs implementation)

## Building and Running

```bash
# Compile the project
mvn compile

# Run tests
mvn test

# Package the application
mvn package
```

## Assignment

See the `assignment.md` file in the parent directory for detailed requirements.

## Tips

- Read all TODOs in the code
- Start with the class design (Beer types, Brewer types)
- Then implement the Brewery methods
- Finally, write comprehensive tests
- Use Java 21 features where appropriate
- Apply SOLID principles in your design

Good luck!
